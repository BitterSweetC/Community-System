赓续上电红色血脉，绽放社团璀璨风采——我校举办第二十三届学生社团文化节

发表时间：2024-04-15浏览：189

群团闪耀，青春四溢。4月9日晚，我校第23届“赓续上电红色血脉，绽放社团璀璨风采”学生社团文化节开幕式在我校临港校区足球场举办。校团委书记兼学工部副部长马国祥、计算机科学与技术学院党委副书记齐永晓，以及学校各部门、各学院相关教师20余人出席活动，数千名学生到场观看。精彩纷呈的演出，趣味十足的游戏，伴着耀眼的灯光和闪烁的荧光棒，和不时响起的节拍声、掌声、喝彩声、欢呼声、呐喊声，激荡起澎湃上电的青春热浪。偶尔双腿也会松懈，但我不会退缩，一切对我来说都轻而易举。开幕式在Revolution街舞社带来的舞蹈《easy》中拉开帷幕，独特的创意与动作，帅气的律动与张扬，将青春的力量与激情演绎得淋漓尽致。你有你的狡猾，我有我的机敏，勇者相逢智者胜。由管弦乐团带来的歌曲《猎狐者》，号声悠扬，宛如英雄的猎狐者一般，沉着而深邃。虽然花费了很多时间自我消化，但我已在另一个层面成为了更好的自己。由麦田音乐社演奏的歌曲《Don't start now》，声音如振翅欲飞的蝴蝶，缥缈悠然，饱含深情，扣人心弦。日出江花红胜火，春来江水绿如蓝，能不忆江南？由舞蹈团带来的古典舞《入画江南》，尽显江南女子柔情。曼妙的舞步，如轻云般飘移，亭亭翠玉，盈盈素靥，在身影翩蝶间，演绎祖国壮美山河。坚持不懈，即使不被理解，也要创造属于自己的奇幻故事。由SKY动漫社带来的歌曲《翻滚少女》，伴着刚劲有力的荧光，尽显倔强与坚毅。月光下的白玫瑰，交相辉映你的美，擦干悲伤的眼泪，努力向前，誓要与你相遇。由EP制噪说唱社带来的原创作品《行人的泪》，含情脉脉，宛转悠扬，爱情的坚贞与不屈随歌绽放！科技创新是发展新质生产力的核心要素。由电子学社带来的独特表演《机器人总动员》惊艳四方，机器人自由穿梭，无人机翩翩飞舞，酷炫的科技范激起了同学们对科技创新的热切渴盼。就算不能在你身旁，也要做你的太阳，奋力为你而发光。由合唱团带来的歌曲《太阳》，真挚热烈，唱出了新时代上电青年为爱发光的青春宣言。追逐光、靠近光、成为光、散发光。由朗诵团带来的作品《追光》，诠释了新时代的上电青年，赓续红色血脉，继承先辈遗志，争做光明使者的责任与担当。披星戴月，走过的路，最终将会繁华遍地。由校学生社团管理中心带来的合唱《夜空中最亮的星》，声情并茂，伴着手电筒摆动的点点星光，辉映出我校学生社团管理中心昂扬向上的精神风貌。兄弟高校学生社团也受邀在开幕式中热情出演。由上海海洋大学岳渲表演社带来的相声《素质》，令同学们捧腹大笑。由上海工程技术大学歌唱社带来的歌曲《打开》，情深深、意绵绵。由上海建桥学院DopeTeam舞团带来的舞蹈《ICKY》，热力四射，动感青春。兄弟高校社团的出演，丰富了开幕式的内容和形式，也深化了彼此的友谊。除主舞台举办的精品社团风采秀外，交相辉映的星光游园会同样摩肩接踵，人山人海。同学们以志趣为媒，交流、互动、切磋，欢乐的笑声在校园如碧波荡漾。本届校学生社团文化节开幕式由校党委学生工作部、校团委主办，校学生社团管理中心承办，人文艺术学院等各学生社团业务指导单位积极协助。接下来，光予文学社、纵横辩论社、羽毛球社、书画印协会、麦田音乐社、学生模拟政协协会、合唱团、民乐团、红十字会等学生社团将纷纷开设专场，以青春之姿为繁荣校园文化生活贡献社团力量！
