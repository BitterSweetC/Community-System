\section{功能性需求}

\subsection{用户管理需求}

\begin{enumerate}
  \item 支持邮箱验证码注册，密码需满足强度要求（8位以上，含字母与数字）；
  \item 支持账号密码登录，登录失败超过5次后锁定账户15分钟；
  \item 支持通过邮箱验证码找回密码；
  \item 用户可维护个人信息（头像、昵称、联系方式等）；
  \item 基于RBAC模型实现细粒度权限控制，不同角色访问不同功能模块。
\end{enumerate}

\subsection{社团管理需求}

\begin{enumerate}
  \item 学生可提交社团创建申请，填写社团名称、类型、简介等信息；
  \item 系统管理员对申请进行审批（通过/拒绝），审批结果通过通知推送给申请人；
  \item 社团管理员可管理成员（邀请、移除、设置角色）；
  \item 社团生命周期包含：申请中→活跃→冻结→解散四个状态，管理员可对社团执行冻结与解散操作；
  \item 支持社团信息编辑（头像、简介、联系方式等）。
\end{enumerate}

\subsection{活动管理需求}

\begin{enumerate}
  \item 社团管理员可发布活动，填写活动名称、时间、地点、人数上限等信息；
  \item 普通用户可报名参加活动，报名人数达到上限后自动关闭报名；
  \item 系统生成唯一签到码，参与者扫码或输入签到码完成签到；
  \item 活动结束后，管理员可导出签到数据（Excel格式）；
  \item 支持活动状态管理（草稿→发布→进行中→已结束→已归档）。
\end{enumerate}

\subsection{招募管理需求}

\begin{enumerate}
  \item 社团管理员可创建招募批次，设置招募时间、名额等参数；
  \item 支持动态表单配置，管理员可自定义申请表字段（文本、单选、多选等）；
  \item 招募申请支持多阶段审核流程（初审→复审→录取/淘汰）；
  \item 申请状态变更时，系统自动向申请人发送通知。
\end{enumerate}

\subsection{通知公告需求}

\begin{enumerate}
  \item 系统管理员可发布全局公告，社团管理员可发布社团内部公告；
  \item 基于WebSocket实现实时通知推送，用户在线时即时收到通知；
  \item 系统记录通知已读状态，支持未读数量统计与批量标记已读；
  \item 支持通知类型分类（系统通知、活动通知、招募通知等）。
\end{enumerate}

\subsection{财务管理需求}

\begin{enumerate}
  \item 社团管理员可记录收支流水（收入/支出类型、金额、说明）；
  \item 大额支出需经系统管理员审批；
  \item 系统自动计算社团余额，余额不足时禁止支出操作；
  \item 支持财务数据按时间范围查询与统计图表展示。
\end{enumerate}

\subsection{资源管理需求}

\begin{enumerate}
  \item 系统管理员维护可用资源列表（场地、设备等）；
  \item 社团管理员可提交资源申请，指定使用时间段；
  \item 系统自动检测时间段冲突，冲突时拒绝申请；
  \item 申请经系统管理员审批后生效，结果通知申请人。
\end{enumerate}

\subsection{AI 智能服务需求}

\begin{enumerate}
  \item 系统根据用户历史行为与社团内容，为用户推荐感兴趣的社团；
  \item 用户可通过自然语言向AI助手提问，获取社团相关信息的智能解答；
  \item 管理员可触发知识库同步，将最新社团数据更新至向量数据库。
\end{enumerate}

\section{非功能性需求}

\begin{enumerate}
  \item \textbf{安全性}：所有接口需经过身份认证，敏感操作记录审计日志；防范SQL注入、XSS、CSRF等常见攻击；
  \item \textbf{性能}：核心查询接口（社团列表、活动列表）响应时间不超过200ms；系统支持100并发用户同时在线；
  \item \textbf{可用性}：系统提供完善的异常处理机制，单一模块故障不影响其他模块正常运行；
  \item \textbf{可扩展性}：模块化架构设计，新增业务模块无需修改现有代码；
  \item \textbf{易用性}：前端界面简洁直观，核心操作步骤不超过3步。
\end{enumerate}
