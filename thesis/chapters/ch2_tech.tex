\chapter{相关技术介绍}

\section{后端技术栈}

\subsection{Spring Boot 3.x 框架}

Spring Boot是由Pivotal团队基于Spring框架开发的快速应用开发框架，其核心设计理念是"约定优于配置"（Convention over Configuration）。Spring Boot 3.x基于Spring Framework 6.x构建，要求JDK 17及以上版本，全面支持Jakarta EE 9+规范\cite{springboot2023}。

Spring Boot的自动配置机制通过\texttt{@EnableAutoConfiguration}注解与\texttt{spring.factories}（3.x改为\texttt{AutoConfiguration.imports}）文件，在应用启动时根据类路径中的依赖自动装配所需Bean，极大简化了项目配置工作。

本系统采用Maven多模块项目结构，将业务逻辑按职责拆分为独立模块（如\texttt{community-club}、\texttt{community-activity}等），各模块作为\texttt{community-gateway}的依赖，最终打包为单一可部署JAR，兼顾了代码组织的清晰性与部署的简便性。

\subsection{Spring Security 与 JWT 认证}

Spring Security是Spring生态中功能最为完善的安全框架，提供认证（Authentication）与授权（Authorization）的全面支持。本系统基于Spring Security 6.x的无状态安全配置，结合JWT（JSON Web Token）实现分布式认证。

JWT由三部分组成：Header（头部）、Payload（载荷）与Signature（签名），三部分以Base64URL编码后用"."连接，格式如下：

\begin{equation}
  \text{JWT} = \text{Base64URL}(\text{Header}) \cdot \text{Base64URL}(\text{Payload}) \cdot \text{HMACSHA256}(\text{Header}+\text{Payload}, \text{secret})
\end{equation}

本系统采用Access Token（有效期2小时）与Refresh Token（有效期7天）的双令牌机制。Access Token存储于内存，Refresh Token以HttpOnly Cookie方式存储，有效防御XSS攻击。Token黑名单通过Redis实现，登出时将Token加入黑名单，确保即时失效。

\subsection{Spring Data JPA 与 MySQL 8}

Spring Data JPA基于Hibernate ORM实现，通过Repository接口模式屏蔽底层SQL细节，支持方法名推导查询、\texttt{@Query}注解自定义JPQL/原生SQL及Specification动态查询\cite{jpa2022}。

MySQL 8引入了窗口函数、公共表表达式（CTE）、JSON数据类型等特性，本系统利用其CHECK约束保证数据完整性，并通过合理设计复合索引优化高频查询性能。

\subsection{Redis 缓存与会话管理}

Redis作为内存数据库，在本系统中承担以下职责：
\begin{enumerate}
  \item \textbf{分布式缓存}：缓存社团列表、活动信息等热点数据，减少数据库压力；
  \item \textbf{登录限流}：基于滑动窗口算法，对同一IP的登录失败次数进行计数，超过阈值后锁定账户；
  \item \textbf{Token黑名单}：存储已登出的Token，过期时间与Token有效期一致，实现精确失效控制；
  \item \textbf{验证码存储}：邮箱验证码以TTL键值对形式存储，自动过期。
\end{enumerate}

\subsection{RabbitMQ 消息队列}

RabbitMQ基于AMQP协议，支持多种消息交换模式。本系统采用Topic Exchange实现消息路由，将通知发送、邮件推送等耗时操作从主业务流程中解耦，通过异步消息驱动架构提升系统响应速度与吞吐量。

\subsection{阿里云OSS对象存储}

阿里云对象存储服务（OSS）提供高可靠、低成本的非结构化数据存储能力。本系统通过OSS Java SDK实现社团头像、活动封面等图片文件的上传与管理，支持预签名URL实现安全的直传与访问控制。

\section{前端技术栈}

\subsection{Vue 3 + Vite}

Vue 3采用Composition API，通过\texttt{setup()}函数将相关逻辑组合在一起，相比Options API具有更好的逻辑复用性与TypeScript支持。Vite基于原生ES模块实现极速冷启动与热模块替换（HMR），显著提升开发体验\cite{vue3docs}。

\subsection{Pinia 状态管理}

Pinia是Vue 3官方推荐的状态管理库，相比Vuex具有更简洁的API与更好的TypeScript类型推断。本系统使用Pinia管理用户认证状态（Token、用户信息、权限列表），并通过\texttt{pinia-plugin-persistedstate}实现状态持久化，防止页面刷新后登录状态丢失。

\subsection{Element Plus UI组件库}

Element Plus是基于Vue 3的企业级UI组件库，提供丰富的表单、表格、对话框等组件。本系统基于Element Plus构建管理后台界面，利用其表单验证机制实现前端数据校验，减少无效请求。

\subsection{WebSocket（STOMP/SockJS）}

WebSocket协议提供全双工通信能力，相比HTTP轮询具有更低的延迟与资源消耗。本系统后端基于Spring WebSocket与STOMP协议实现消息代理，前端通过SockJS（提供WebSocket降级兼容）连接，实现活动签到实时广播与系统通知即时推送。

\subsection{ECharts 数据可视化}

Apache ECharts是百度开源的高性能可视化库，支持折线图、柱状图、饼图等多种图表类型。本系统利用ECharts构建实时数据大屏，展示今日签到趋势、社团活跃度分布、财务收支统计等可视化内容。

\section{AI 智能服务}

\subsection{DeepSeek 大语言模型}

DeepSeek是国内领先的大语言模型，提供兼容OpenAI接口规范的API服务。本系统通过DeepSeek API实现自然语言理解与生成，支撑RAG问答系统的答案生成环节。

\subsection{RAG 检索增强生成}

检索增强生成（Retrieval-Augmented Generation，RAG）是一种将信息检索与语言模型生成相结合的技术范式\cite{lewis2020rag}。其核心流程如下：

\begin{enumerate}
  \item \textbf{知识库构建}：将社团简介、活动规则等文档切分为文本块，通过Embedding模型向量化后存入Chroma向量数据库；
  \item \textbf{检索}：用户提问经向量化后，在Chroma中进行相似度检索，获取最相关的文本块；
  \item \textbf{生成}：将检索结果与用户问题拼接为Prompt，调用DeepSeek API生成最终答案。
\end{enumerate}

本系统使用LangChain框架编排上述流程，实现了可维护、可扩展的RAG问答服务。

\subsection{混合推荐算法}

本系统采用协同过滤与内容推荐相结合的混合推荐策略：

\begin{enumerate}
  \item \textbf{SVD协同过滤}：基于用户-社团交互矩阵（加入、收藏、浏览等行为），通过奇异值分解（SVD）学习用户与社团的潜在特征向量，预测用户对未接触社团的兴趣得分；
  \item \textbf{语义内容推荐}：将社团描述文本向量化，计算用户历史偏好向量与候选社团向量的余弦相似度；
  \item \textbf{混合融合}：对两种算法的得分进行加权融合，综合考虑用户行为与内容语义，提升推荐多样性与准确性。
\end{enumerate}

\section{基础设施与运维}

\subsection{Docker 容器化部署}

Docker通过容器技术实现应用与环境的隔离，确保"一次构建，处处运行"。本系统使用Docker Compose编排Redis、RabbitMQ、Prometheus、Grafana及Python Agent等服务，通过\texttt{docker-compose.yml}统一管理服务依赖与网络配置，简化开发与部署流程。

\subsection{Prometheus + Grafana 监控}

Prometheus是云原生领域主流的监控系统，采用拉取（Pull）模式定期抓取目标服务的指标数据。本系统通过Spring Boot Actuator暴露\texttt{/actuator/prometheus}端点，Prometheus每15秒抓取一次JVM内存、HTTP请求延迟、数据库连接池等指标，Grafana连接Prometheus数据源，提供可视化监控仪表盘。
