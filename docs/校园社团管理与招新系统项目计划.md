# 校园社团管理与招新系统 - 项目计划

## 1. 项目概述
- 项目名称：校园社团管理与招新系统
- 当前形态：`Spring Boot` 多模块单体 + `Vue 3` 前端 + `FastAPI` 智能体服务
- 当前交付范围：认证、社团、招新、活动、公告通知、资源、财务、统计、审计、AI 问答与推荐

## 2. 当前里程碑状态
结合仓库现状，核心功能已经进入“可运行 + 可继续完善”阶段：

| 阶段 | 当前状态 | 说明 |
|------|----------|------|
| 基础框架 | 已完成 | Maven 多模块、统一启动、Docker Compose |
| 认证与安全 | 已完成基础版 | JWT、Cookie、Redis、验证码、登录限流 |
| 社团与招新 | 已完成基础版 | 社团、成员、招新批次、报名、审核、导出 |
| 活动与公告 | 已完成基础版 | 活动报名、签到、公告、通知 |
| 资源与财务 | 已完成基础版 | 资源审批、财务审批 |
| AI 能力 | 已接入 | 问答、推荐、知识同步 |
| 监控 | 已接入基础版 | Prometheus、Grafana、指标暴露 |
| 自动化测试 | 部分完成 | 认证、用户、社团有单元测试，覆盖仍可加强 |

## 3. 后续工作建议

### 3.1 短期
- 补齐数据库初始化脚本与迁移说明。
- 清理配置中的明文敏感信息，改为环境变量注入。
- 补充更多接口级与服务级测试。
- 统一前后端分页与错误码约定。

### 3.2 中期
- 完善推荐理由展示与 AI 输出约束。
- 优化资源、财务、统计模块的前后端联动体验。
- 增强监控告警与运行日志整理。

### 3.3 长期
- 视规模决定是否将 AI、通知或统计能力进一步独立部署。
- 增加更多数据分析报表。
- 继续打磨前端交互和权限边界。
