# RAG & Recommendation System Implementation Plan

## 1. Python RAG Agent (`agent/`)
Create a FastAPI-based service to handle retrieval-augmented generation using the existing crawled data.

### 1.1 Dependencies & Setup
- Update `agent/requirements.txt` with `fastapi`, `uvicorn`, `langchain`, `chromadb`, `sentence-transformers`, `openai`.
- Create `agent/Dockerfile` for containerization.

### 1.2 RAG Logic (`agent/rag.py`)
- **Vector Store**: Use **ChromaDB** with `all-MiniLM-L6-v2` embeddings (CPU-friendly).
- **Initialization**: On startup, load `.md` files from `agent/data/`, split into chunks, and index them.
- **Query Processing**:
  - Retrieve top-k relevant chunks for the user query.
  - Construct prompt with Context + Query.
  - Call DeepSeek API via LangChain's `ChatOpenAI` adapter.

### 1.3 API Layer (`agent/main.py`)
- `POST /chat`: Accepts user query, performs RAG, returns answer.
- `POST /sync`: Accepts structured data (Club/Activity info) from Spring Boot to update the vector index dynamically.

## 2. Spring Boot Integration (`community-club`)

### 2.1 Chat Service Update
- Refactor `ChatServiceImpl.java`:
  - Replace direct DeepSeek API call with a REST call to `http://rag-service:8000/chat`.
  - Pass user query to the Python agent.

### 2.2 Recommendation System (FR-AI-REC)
- **Constraint**: Omit "Skills" based recommendation as requested.
- **Logic**:
  - **Logged-in User**: Match `User.interests` with `Club.category` and `Club.tags`.
  - **Fallback/Guest**: Return top clubs by `visitCount`.
- **Implementation**:
  - Modify `ClubRepository` to add matching queries.
  - Add `getRecommendedClubs` method in `ClubService`.
  - Expose `GET /api/clubs/recommended` in `ClubController`.

## 3. Infrastructure
- Update `docker-compose.yml`:
  - Add `rag-service` container.
  - Configure networking to allow Spring Boot to talk to `rag-service`.
