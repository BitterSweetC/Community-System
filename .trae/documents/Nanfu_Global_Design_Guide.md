
本指南旨在详细拆解 `https://www.nanfu.global/` 的视觉设计语言、交互模式及排版布局，帮助开发者根据该风格构建自己的界面。

---

## 1. 核心视觉理念 (Core Visual Concept)

南孚全球站的设计核心在于 **“能量感 (Energy)”**、**“科技感 (Tech)”** 与 **“工业级专业性 (Industrial Professionalism)”**。它通过大面积的深色背景、极具冲击力的产品摄影以及标志性的金色点缀，营造出一种高端、耐用且充满活力的品牌形象。

---

## 2. 色彩规范 (Color Palette)

南孚的色彩运用极其精准，主要围绕电池产品的物理特性展开：

| 颜色类别 | 十六进制代码 (HEX) | 应用场景 |
| :--- | :--- | :--- |
| **背景主色 (Background)** | `#000000` | 页面背景，营造深邃、高端的科技感。 |
| **核心强调色 (Gold)** | `#D4AF37` / `#FFD700` | 聚能环、按钮悬停、关键标题、技术亮点。 |
| **科技辅助色 (Blue)** | `#00AEEF` | 碱性技术展示、实验室场景、冷色调对比。 |
| **正文主色 (White)** | `#FFFFFF` | 主标题、重要文案。 |
| **正文副色 (Gray)** | `#999999` / `#CCCCCC` | 副标题、说明性文字、页脚。 |

---

## 3. 字体与排版 (Typography)

*   **字体族**: 优先选用现代、硬朗的无衬线字体 (Sans-serif)。
    *   *推荐字体*: Inter, Helvetica Neue, Arial, 或者 Google Fonts 上的 *Oswald* (适合标题)。
*   **标题样式**:
    *   **主标题 (Hero)**: 字号 48px - 72px，字重 Black (900)，全大写，字间距 (letter-spacing) 略微压缩 (-0.02em)。
    *   **板块标题**: 字号 32px - 40px，字重 Bold (700)，常带下划线或金色装饰线。
*   **正文样式**:
    *   字号 16px - 18px，行高 (line-height) 1.6 - 1.8，确保在黑色背景下不粘连。
*   **对齐方式**: 大量采用居中对齐以体现“平衡感”，或在大图左侧进行强力左对齐。

## 4. 关键 UI 组件与布局结构

### 4.1 沉浸式首屏 (Hero Section)
*   **背景**: 使用极高分辨率的产品微距大图。背景应经过暗角处理，确保中间的产品（如电池或聚能环）是唯一的视觉焦点。
*   **动态效果**: 建议在聚能环处增加微弱的脉冲发光效果 (`box-shadow` 动画)。
*   **Call to Action (CTA)**: 按钮采用金色边框或金色填充，悬停时产生扫光动画。

### 4.2 能量环技术展示 (Power Ring Section)
*   **视觉逻辑**: 采用圆环元素作为视觉中心。
*   **布局**: 左右分割。左侧为动态展示的圆环/电池剖面，右侧为技术参数（如“提升 25% 续航”）。
*   **色彩**: 强调金色与黑色的对比。

### 4.3 发展历程时间轴 (History Timeline)
*   **样式**: 极简的垂直线或水平线。
*   **交互**: 鼠标滑过年份时，年份文字变大并变色（灰变金），同时弹出对应年份的里程碑图片。
*   **视觉细节**: 使用金色圆点标记关键年份。

### 4.4 磁贴式功能卡片 (Feature Grid)
*   **结构**: 3列或4列布局。
*   **背景**: 深灰色半透明背景 (`rgba(30, 30, 30, 0.8)`)，带有模糊效果 (backdrop-filter: blur)。
*   **图标**: 极细线条图标 (Thin Stroke Icons)，颜色统一为金色。

---

## 5. 交互与动效建议

1.  **滚动触发 (Scroll Reveal)**: 元素不应一次性加载，而是随着滚动从下方 20px 处淡入。
2.  **视差滚动 (Parallax)**: 电池产品图随鼠标移动产生轻微的位移偏移，增加空间感。
3.  **光效追踪**: 在鼠标移动时，页面背景可以有极微弱的金色光点跟随，模拟电离子。
4.  **平滑过渡**: 所有的色彩变化和大小缩放应在 0.3s - 0.5s 内平滑完成。

## 6. 开发建议 (前端实现)

*   **框架**: Vue 3 + Tailwind CSS。
*   **CSS 特效示例 (金色发光按钮)**:
    ```css
    .btn-nanfu {
      background: linear-gradient(45deg, #D4AF37, #F9D976);
      color: black;
      font-weight: bold;
      box-shadow: 0 0 15px rgba(212, 175, 55, 0.4);
      transition: all 0.3s ease;
    }
    .btn-nanfu:hover {
      box-shadow: 0 0 25px rgba(212, 175, 55, 0.7);
      transform: translateY(-2px);
    }
    ```
*   **图片素材**: 必须使用 2x 或 3x 的高清素材，深色背景对低质量图片的容忍度极低。
