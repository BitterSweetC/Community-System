您提到的 `@Transient` 注解正是用于标记那些不需要持久化到数据库的字段。JPA/Hibernate 会自动忽略这些字段，不会尝试将它们映射到数据库列。

以下是实现方案：

### 1. 修改 `Club` 实体类
在 `Club.java` 中添加两个字段，并加上 `@Transient` 注解。

```java
@Transient
private Long memberCount = 0L;

@Transient
private Long activityCount = 0L;
```

### 2. 修改 `ClubVO` 类
为了让前端能接收到这些数据，需要在视图对象 `ClubVO.java` 中也添加对应字段，并更新转换逻辑。

```java
private Long memberCount;
private Long activityCount;

// 在 from 方法中
vo.setMemberCount(club.getMemberCount());
vo.setActivityCount(club.getActivityCount());
```

### 3. 修改 `ClubServiceImpl`
在 Service 层查询社团信息时，动态填充这两个字段。为了复用逻辑，我将增加一个辅助方法 `populateClubStats`。

需要修改的方法包括：
- `getClubById`: 获取详情时填充。
- `getMyClubs`: 获取我的社团列表时填充（用于 Dashboard 展示）。
- `getRecommendedClubs`: 推荐列表也建议填充。
- `searchClubs` / `getAllClubs`: 考虑到性能（N+1查询问题），如果是分页查询，可以填充；如果是全量列表可能较慢，但对于目前的规模可以接受。

**辅助方法逻辑：**
```java
private void populateClubStats(Club club) {
    if (club == null) return;
    club.setMemberCount(memberRepository.countByClubId(club.getId()));
    club.setActivityCount(activityRepository.countByClubId(club.getId()));
}
```
