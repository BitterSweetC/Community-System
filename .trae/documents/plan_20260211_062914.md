我将为你部署一套完整的 Prometheus + Grafana 监控系统，并将其集成到你现有的 Docker 环境中。

### 1. 后端改造 (Java)

让 Spring Boot 应用暴露 Prometheus 可读的监控指标。

* **文件**: `community-gateway/pom.xml`

  * 添加 `spring-boot-starter-actuator` (监控核心)

  * 添加 `micrometer-registry-prometheus` (数据格式转换)

* **文件**: `community-gateway/src/main/resources/application.properties`

  * 开放 `/actuator/prometheus` 端点

  * 开启指标收集

### 2. 创建 Prometheus 配置

配置 Prometheus 去哪里抓取数据。

* **新建文件**: `monitoring/prometheus.yml`

  * 配置抓取任务 `community-backend`

  * 目标地址设为 `host.docker.internal:8080` (因为你的 Java 应用运行在宿主机 IDEA 中，而 Prometheus 运行在 Docker 容器里)

### 3. 更新 Docker 环境

将监控组件加入你现有的 Docker Compose 编排。

* **修改文件**: `docker-compose.yml`

  * 新增服务 `prometheus` (端口 9090)

  * 新增服务 `grafana` (端口 3000)

  * 挂载配置文件和数据卷

### 4. 验证与使用

* 重启 Java 应用

* 重启 Docker Compose (`docker-compose up -d`)

* 访问 Grafana 面板并导入 JVM 监控模板
