# 实施预定义资源管理与冲突检测

## 后端开发
1.  **创建实体与仓库**
    *   新建 `Resource` 实体类，定义资源属性（名称、类型、容量等）。
    *   新建 `ResourceRepository` 接口。
2.  **更新现有实体**
    *   修改 `ResourceApplication` 实体，将 `resourceName` 和 `type` 字段替换为 `Resource` 实体的关联对象。
3.  **数据库变更**
    *   更新 `schema.sql`，添加 `t_resource` 表定义，并修改 `t_resource_application` 表结构以包含 `resource_id` 外键。
4.  **业务逻辑实现**
    *   在 `ResourceService` 和 `ResourceServiceImpl` 中实现资源定义的增删改查方法。
    *   实现 `findConflictingApplications` 方法，在申请资源时检查时间冲突。
5.  **API 接口开发**
    *   更新 `ResourceController`，增加资源管理的 CRUD 接口。

## 前端开发
1.  **新增资源定义页面**
    *   创建 `src/views/admin/AdminResourceDefinition.vue`，供系统管理员管理资源。
2.  **更新路由与导航**
    *   在 `router/index.js` 中添加资源定义页面的路由。
    *   在 `views/admin/Layout.vue` 中添加“资源定义”菜单项。
3.  **更新资源申请页面**
    *   修改 `views/admin/ResourceManagement.vue`（社团资源管理），将手动输入改为从下拉列表中选择预定义资源。
    *   修改 `views/admin/ActivityManagement.vue`（活动管理），同样集成资源选择下拉列表。
4.  **更新资源审批页面**
    *   修改 `views/admin/AdminResourceApproval.vue`，适配新的数据结构显示资源信息。

## 验证与测试
1.  **功能验证**
    *   验证系统管理员能否成功添加、编辑、删除资源。
    *   验证社团管理员能否在申请时看到资源列表并选择。
    *   验证时间冲突检测逻辑：尝试在同一时间段申请同一资源，预期被拒绝。
