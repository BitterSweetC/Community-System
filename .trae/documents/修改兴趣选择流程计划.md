# 修改兴趣选择流程计划

## 1. 修改兴趣组件数据 (`src/components/InterestSelector.vue`)
更新预定义的兴趣列表，使其更贴近社团活动（如体育、艺术、学术等）。
*   **新列表内容示例**：
    *   体育类：篮球、足球、羽毛球、乒乓球、游泳、跑步
    *   艺术类：绘画、摄影、书法、舞蹈、声乐、乐器
    *   学术类：编程、阅读、数学建模、英语角
    *   其他：志愿服务、电子竞技、棋牌、电影

## 2. 移除注册时的兴趣选择 (`src/views/RegisterView.vue`)
*   删除引入的 `InterestSelector` 组件。
*   删除 `selectedInterests` 状态变量。
*   删除提交数据中的 `interests` 字段，恢复为仅提交用户名、密码、真实姓名。
*   删除表单中的“兴趣爱好” `el-form-item`。

## 3. 在首页添加兴趣选择弹窗 (`src/views/student/HomeView.vue`)
*   **引入组件**: 引入 `InterestSelector` 和 `el-dialog`。
*   **状态管理**:
    *   `showInterestDialog` (Boolean): 控制弹窗显示。
    *   `selectedInterests` (Array): 绑定用户选择的兴趣。
    *   `savingInterests` (Boolean): 保存时的加载状态。
*   **逻辑实现**:
    *   在 `onMounted` 中，检查当前用户 (`authStore.user`) 的 `interests` 字段。
    *   如果 `interests` 为空或 null，则设置 `showInterestDialog = true`。
    *   实现 `saveInterests` 方法：
        *   将数组转换为逗号分隔字符串。
        *   调用 `PUT /api/users/me` 更新用户信息。
        *   更新 `authStore` 中的用户信息。
        *   关闭弹窗并提示成功。
*   **UI 实现**:
    *   添加一个 `el-dialog`，标题为“选择您的兴趣爱好”。
    *   内容区域放入 `InterestSelector`。
    *   底部按钮：“跳过”（可选，或强制选择）和“保存”。建议强制选择或提供“暂不选择”。用户意图似乎是引导选择，设置为必须选择或允许关闭但下次还会弹？简单起见，提供“保存”按钮，允许关闭。

## 4. 验证
*   注册新用户，确认注册流程不再询问兴趣。
*   新用户登录后进入首页，确认弹出兴趣选择框。
*   选择兴趣并保存，确认弹窗关闭且数据已更新。
*   再次刷新首页，确认弹窗不再出现。
