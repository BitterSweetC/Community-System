# 增加用户兴趣爱好功能计划

## 后端修改
1.  **修改数据库 Schema**:
    *   在 `community-gateway/src/main/resources/schema.sql` 中的 `t_user` 表添加 `interests` 字段 (`VARCHAR(500)`).
2.  **修改实体类**:
    *   在 `community-core/src/main/java/com/cloud/community/core/entity/User.java` 中添加 `private String interests;` 字段及 Getter/Setter。
3.  **修改控制器逻辑**:
    *   `UserController.java` (`updateProfile` 方法): 增加对 `interests` 字段的更新处理。
    *   `AuthController.java` (`register` 方法): 由于直接使用 `User` 实体接收参数，无需额外修改，只需确保前端传递该字段即可。

## 前端修改
1.  **修改注册页面 (`frontend/src/views/RegisterView.vue`)**:
    *   在注册表单中增加“兴趣爱好”输入框（可以是文本框或多选标签，根据简单实现原则，先做成文本框或逗号分隔的输入）。
    *   修改提交逻辑，将 `interests` 字段包含在注册请求中。
2.  **修改用户个人中心 (`frontend/src/views/student/UserProfileView.vue`)**:
    *   在个人资料展示区域增加“兴趣爱好”字段。
    *   在编辑模式下允许修改“兴趣爱好”。
    *   **修复潜在 Bug**: 确认并修正 API 调用路径，将 `/users/profile` 更正为 `/users/me` 以匹配后端接口。

## 验证计划
1.  **注册流程**: 使用新字段注册一个新用户，检查数据库是否正确保存。
2.  **用户中心**: 登录后进入个人中心，查看是否显示兴趣爱好。
3.  **修改资料**: 在个人中心修改兴趣爱好，保存后刷新，确认修改生效。
