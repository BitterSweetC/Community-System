I will implement the Finance Management frontend module, providing interfaces for both Club Admins (to manage finances) and System Admins (to audit).

### 1. API Integration (`src/api/finance.js`)
Create a new API module to handle communication with the existing backend `FinanceController`:
- `getClubTransactions(clubId)`: Fetch transaction history.
- `createTransaction(data)`: Submit new income/expense records.
- `getClubBalance(clubId)`: Retrieve current club balance.
- `approveTransaction(id)`: Approve a pending transaction (System Admin).
- `rejectTransaction(id)`: Reject a pending transaction (System Admin).

### 2. Frontend View (`src/views/admin/FinanceManagement.vue`)
Create a comprehensive `FinanceManagement.vue` component that adapts based on the user's role:
- **Common Features**:
    - **Balance Display**: Show the current available balance at the top.
    - **Transaction History**: A data table showing ID, Type (Income/Expense), Amount, Title, Status, Applicant, and Date.
- **Club Admin Features**:
    - **"Record Transaction" Button**: Opens a dialog to submit new Income or Expense requests.
    - **Form Fields**: Type, Amount, Title, Description, Proof URL.
- **System Admin Features**:
    - **Audit Actions**: "Approve" and "Reject" buttons visible only for `PENDING` transactions.
    - **Read-Only View**: Cannot submit new transactions, only audit existing ones.

### 3. Routing Configuration (`src/router/index.js`)
Register the new view in the router with role-based access:
- **System Admin Route**: `/admin/finance/:clubId` (Accessed via Club Management).
- **Club Admin Route**: `/clubadmin/finance/:clubId` (Accessed via Sidebar).

### 4. Navigation Updates
- **For Club Admins (`src/views/admin/Layout.vue`)**:
    - Add a "Finance Management" link to the sidebar menu under the specific club's submenu.
- **For System Admins (`src/views/admin/ClubManagement.vue`)**:
    - Add a "Finance Audit" button to the club list table, allowing System Admins to jump directly to the finance page for a specific club.
