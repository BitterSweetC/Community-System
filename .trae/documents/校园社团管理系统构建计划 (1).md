# 校园社团管理系统构建计划

根据您的需求，我制定了以下全栈开发计划，严格遵循企业级规范，数据库使用 MySQL，后端使用 Spring Boot，前端使用 Vue 3。

## 🛠️ 技术栈与规范
- **后端**: Spring Boot 3.2, Spring Data JPA, Spring Security + JWT
- **数据库**: MySQL 8.0 (基于已有的 schema.sql)
- **前端**: Vue 3 (Composition API), Vite, Vue Router, Pinia, Axios, Element Plus (用于快速构建后台管理界面)
- **规范**: 
  - 后端采用 `Controller` -> `Service` (Interface) -> `ServiceImpl` -> `Repository` 分层架构。
  - 前端区分 `Student` (前台) 和 `Admin` (后台) 两个视图模块。

## 📅 实施步骤

### 第一阶段：后端核心架构 (Backend Core)
1.  **实体映射 (Entities)**: 根据 `schema.sql` 创建对应的 JPA Entity 类 (`User`, `Club`, `Recruit`, `Activity` 等)。
2.  **数据访问层 (Repository)**: 创建 Repository 接口。
3.  **业务逻辑层 (Service)**: 
    - 定义 Service 接口 (如 `UserService`, `ClubService`)。
    - 在 `impl` 包下实现具体逻辑 (如 `UserServiceImpl`)，包含事务管理。
4.  **安全认证 (Security)**: 实现 JWT 过滤器、认证入口点和基于角色的权限控制 (`RBAC`)。

### 第二阶段：业务功能实现 (Business Logic)
1.  **用户模块**: 注册、登录、个人信息修改。
2.  **社团模块**: 
    - 学生：查看列表、申请创建社团。
    - 管理员：审核社团、管理社团成员。
3.  **招新模块**: 
    - 社长：发布招新批次、定义报名表单。
    - 学生：填写表单报名。
    - 社长：审核申请 (初审/复审)。
4.  **活动模块**: 活动发布与报名。

### 第三阶段：前端开发 (Frontend)
1.  **项目初始化**: 在根目录下创建 `frontend` 目录，初始化 Vue 3 + Vite 项目。
2.  **基础建设**: 配置 Axios (拦截器处理 JWT)、Vue Router (路由守卫)、Pinia (用户状态管理)。
3.  **普通用户界面 (Student Portal)**:
    - 首页/社团大厅 (卡片式展示)。
    - 社团详情页 (包含报名入口)。
    - 个人中心 (查看申请进度)。
4.  **管理员界面 (Admin Dashboard)**:
    - 侧边栏导航。
    - 表格化管理 (社团审核、成员管理、招新审批)。

### 第四阶段：测试与交付 (Testing)
1.  **后端测试**: 编写 JUnit 测试用例，覆盖核心业务流程。
2.  **联调测试**: 前后端联调，验证完整流程 (注册 -> 申请社团 -> 审核 -> 发布招新 -> 报名 -> 录取)。
