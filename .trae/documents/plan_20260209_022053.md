# Implementation Plan: AI Agent (RAG) & Club Recommendation

## 1. AI Agent Service (Python)
Create a new standalone Python service in `agent/` directory to handle RAG (Retrieval-Augmented Generation).
*   **Tech Stack**: FastAPI, SQLAlchemy (for DB access), OpenAI Client (for DeepSeek).
*   **Directory Structure**:
    ```text
    agent/
      ├── Dockerfile
      ├── requirements.txt
      ├── main.py           # FastAPI app entry point
      ├── database.py       # Database connection
      ├── models.py         # SQLAlchemy models (Club, Activity)
      └── rag_service.py    # RAG logic (Search + Prompt + LLM)
    ```
*   **Functionality**:
    *   Connect to the shared MySQL database.
    *   Expose `POST /chat` endpoint.
    *   **RAG Logic**: 
        1.  Receive user query.
        2.  Retrieve active Clubs and recent Activities from DB.
        3.  Build context prompt with system instructions + retrieved data.
        4.  Call DeepSeek API with context.
        5.  Return answer.

## 2. Infrastructure & Deployment
*   **Docker Compose**: Update `docker-compose.yml` to include the `ai-agent` service.
    *   Build context: `./agent`
    *   Port: `8000:8000`
    *   Environment variables: DB connection, DeepSeek API Key.

## 3. Backend Integration (Spring Boot)
*   **ChatService Refactoring**: 
    *   Modify `ChatServiceImpl.java` in `community-club`.
    *   Replace direct DeepSeek API call with a call to the local Python Agent (`http://ai-agent:8000/chat` or `http://localhost:8000/chat` depending on env).
    *   Update `application.yml` with `ai.agent.url`.

## 4. Recommendation System (FR-AI-REC)
Implement "Recommended Clubs" based on user interests (omitting skills/recruitment recommendation per request).
*   **ClubService**: 
    *   Add `List<ClubVO> getRecommendedClubs(Long userId)`.
    *   Logic:
        *   Fetch `User.interests`.
        *   Fetch all active `Club`s.
        *   **Matching**: Score clubs by matching `User.interests` words against `Club.category` and `Club.tags`.
        *   **Sorting**: Sort by Score (Desc) -> VisitCount (Desc).
*   **ClubController**: 
    *   Add endpoint `GET /api/clubs/recommended`.
