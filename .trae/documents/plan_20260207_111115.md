# Implement System Audit Log (FR-SYS-01)

I will implement a complete audit logging system to record sensitive operations (Login, Permission Changes, Approvals).

## Backend Implementation

### 1. Core Infrastructure (`community-core`)

* **Repository**: Create `AuditLogRepository` interface extending `JpaRepository`.

* **Service**: Implement `AuditLogService` to handle asynchronous log saving.

* **Annotation**: Create `@AuditLog` annotation to mark methods for auditing.

  * Fields: `action` (e.g., "LOGIN"), `resourceType` (optional).

* **Aspect**: Implement `AuditLogAspect` using Spring AOP.

  * Intercepts methods with `@AuditLog`.

  * Captures `User` (from SecurityContext), `IP`, `Action`, `Resource`, and `Details`.

  * Saves `AuditLog` entity to database.

### 2. Apply Auditing

I will add `@AuditLog` to the following critical methods:

* **Login**: `AuthController.login`

* **Club Approval**: `ClubController.approveClub`

* **User Status Change**: `AdminController.updateUserStatus`

* **Member Role Change**: `ClubController.updateMemberRole`

### 3. Admin API (`community-admin`)

* **Controller**: Create `AuditLogController`.

* **Endpoints**:

  * `GET /api/admin/audit-logs`: List logs with pagination and filtering (by user, action, date).

## Frontend Implementation

### 1. API Client

* Create `src/api/audit.js` to communicate with the backend.

### 2. Admin Interface

* **Page**: Create `src/views/admin/AuditLogManagement.vue`.

  * Features: Data Table, Search Filter (Action, Username), Pagination.

* **Routing**: Add `/admin/audit` route in `router/index.js`.

* **Navigation**: Add "Audit Logs" item to the Admin Sidebar in `Layout.vue`.
