我将通过引入 **混合推荐系统 (Hybrid Recommendation System)** 和 **矩阵分解 (SVD)** 来显著提升推荐算法的复杂度和准确性。这不仅仅是算法的堆砌，而是为了解决“冷启动”和“稀疏性”问题。

### 1. 算法升级方案

我将对 `agent/recommendation.py` 进行重构，引入以下高级特性：

*   **混合推荐架构 (Hybrid)**:
    *   **Collaborative Filtering (CF)**: 继续保留基于用户行为的推荐，但升级为 **SVD (奇异值分解)** 矩阵分解算法。SVD 能挖掘用户的潜在兴趣特征（Latent Factors），比单纯的 Cosine Similarity 更能处理稀疏矩阵（即用户只互动了极少数社团的情况）。
    *   **Content-Based Filtering (CB)**: 新增基于内容的推荐。利用 `SentenceTransformer` (与 RAG 共享模型) 将社团的 **名称、描述、标签** 转化为高维向量（Embeddings）。
    *   **加权融合**: 最终得分 = `w1 * SVD_Score + w2 * Content_Score`。这能确保即使用户行为很少（CF 失效），也能根据社团内容的语义相似度进行推荐。

*   **时间衰减 (Time Decay)**:
    *   在计算用户行为权重时，引入时间因子。最近的浏览/加入行为权重更高，一年前的行为权重降低。
    *   公式示例：`Score = BaseScore * exp(-decay_rate * days_passed)`。

### 2. 实现步骤

1.  **数据层升级**:
    *   修改 SQL 查询，获取社团的 `description`, `name`, `category` (用于内容推荐)。
    *   修改 SQL 查询，获取行为的 `created_at` (用于时间衰减)。

2.  **模型层升级**:
    *   **SVD 模型**: 使用 `scipy.sparse.linalg.svds` 或 `sklearn.decomposition.TruncatedSVD` 对 User-Item 矩阵进行降维分解。
    *   **Embedding 模型**: 复用 `rag.py` 中的 `SentenceTransformerEmbeddings` 生成社团向量。

3.  **逻辑层升级**:
    *   实现 `HybridRecommender` 类，分别计算 CF 得分和 CB 得分。
    *   对两种得分进行归一化（Min-Max Scaling）后加权求和。

### 3. 预期效果

*   **解决冷启动**: 新社团（无人加入）可以通过内容相似度被推荐给喜欢同类社团的用户。
*   **语义理解**: 系统能理解 "吉他社" 和 "音乐鉴赏" 是相似的（通过 Embedding），即使它们没有共同成员。
*   **捕捉潜意识**: SVD 能发现 "喜欢看展的用户通常也喜欢摄影" 这种潜在关联。
