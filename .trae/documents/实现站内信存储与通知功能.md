我们将按照标准的后端开发流程来完成这个功能：

## 1. 数据库层 (Database)
首先在数据库中创建 `t_notification` 表，用于持久化存储用户的消息。
*   **更新 SQL 脚本**: 在 [schema.sql](file:///e:/IntelliJ IDEA 2024.2.3/code/Community/community-gateway/src/main/resources/schema.sql) 中添加建表语句。
*   **表结构设计**:

    *   `user_id`: 接收消息的用户 ID

    *   `content`: 消息内容
    *   `type`: 消息类型（如 SYSTEM-系统通知, CLUB-社团通知, ACTIVITY-活动通知）
    *   `is_read`: 是否已读状态
    *   `created_at`: 发送时间

*   **创建文件**: `com.cloud.community.core.entity.Notification`

## 3. 数据访问层 (Repository)

*   **功能**: 提供 `findByUserId`（查询某人的消息）、`countByUserIdAndIsReadFalse`（查询未读数量）等方法。

## 4. 业务逻辑层 (Service)

## 5. 接口层 (Controller)
创建新的 API 接口供前端调用。
*   **创建文件**: `com.cloud.community.club.controller.NotificationController`
*   **API 列表**:
    *   `GET /api/notifications`: 获取我的消息列表
    *   `GET /api/notifications/unread/count`: 获取未读消息数量
    *   `PUT /api/notifications/{id}/read`: 标记某条消息为已读
