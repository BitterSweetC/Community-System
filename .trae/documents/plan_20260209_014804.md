# 密码重置功能 (Password Reset) 实施计划

本计划旨在实现基于邮箱验证码的密码重置功能，包括后端邮件发送、验证码管理以及前端页面交互。

## 1. 后端依赖与配置 (Backend)

### 1.1 添加依赖
在 `community-core/pom.xml` 中添加 `spring-boot-starter-mail` 依赖，以便整个项目（包括 Gateway）都能使用邮件服务。

### 1.2 配置文件
在 `community-gateway/src/main/resources/application.properties` 中添加邮件服务配置（SMTP）。
> **注意**: 我将配置为使用 163 邮箱的示例配置，你需要填入真实的 `username` 和 `password` (授权码)。

## 2. 核心服务扩展 (Core Services)

### 2.1 用户数据层
- 修改 `UserRepository`，添加 `Optional<User> findByEmail(String email);` 方法，用于通过邮箱查找用户。

### 2.2 邮件服务
- 在 `community-core` 模块中创建 `EmailService`，封装 `JavaMailSender`，提供发送简单文本邮件的方法。

### 2.3 验证码服务
- 在 `community-core` 模块中创建 `VerificationCodeService`。
- 使用 `RedisTemplate` 存储验证码，键格式为 `auth:code:{email}`，设置过期时间（如 5 分钟）。
- 提供生成、发送（调用 EmailService）和验证验证码的方法。

### 2.4 用户服务更新
- 在 `UserService` 中添加 `updatePassword(Long userId, String newPassword)` 方法，确保新密码经过加密处理（使用 `PasswordEncoder`）。

## 3. API 接口实现 (Gateway)

### 3.1 AuthController 增强
在 `AuthController` 中新增两个公开接口：
1.  `POST /auth/forgot-password`: 接收邮箱地址，检查用户是否存在，若存在则生成并发送验证码。
2.  `POST /auth/reset-password`: 接收邮箱、验证码和新密码。验证通过后更新用户密码。

## 4. 前端开发 (Frontend)

### 4.1 新增忘记密码页面
创建 `frontend/src/views/ForgotPasswordView.vue`，包含两个步骤：
- **步骤 1**: 输入邮箱 -> 点击“获取验证码”。
- **步骤 2**: 输入验证码和新密码 -> 点击“重置密码”。

### 4.2 路由配置
在 `frontend/src/router/index.js` 中添加 `/forgot-password` 路由。

### 4.3 入口链接
在 `LoginView.vue` 的登录表单下方添加“忘记密码？”链接，指向新页面。
