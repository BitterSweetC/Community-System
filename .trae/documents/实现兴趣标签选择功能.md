# 实现兴趣标签选择功能

## 1. 创建兴趣选择组件 (`src/components/InterestSelector.vue`)
创建一个可复用的 Vue 组件，用于展示和选择兴趣标签。
*   **功能**:
    *   展示预定义的兴趣列表（参考截图中的技术栈，但也加入一些通用社团兴趣）。
    *   支持“选择模式”和“只读展示模式”。
    *   UI 样式复刻截图：圆角胶囊状，带首字母图标，选中变色。
*   **数据结构**:
    *   接收 `modelValue` (Array) 作为选中的兴趣列表。
    *   内部维护 `availableInterests` 静态列表。

## 2. 修改注册页面 (`src/views/RegisterView.vue`)
*   引入 `InterestSelector` 组件。
*   将原来的 `el-input` 替换为 `InterestSelector`。
*   逻辑调整：`form.interests` 在提交前将数组转换为逗号分隔的字符串。

## 3. 修改个人中心页面 (`src/views/student/UserProfileView.vue`)
*   引入 `InterestSelector` 组件。
*   **展示状态**: 使用组件的只读模式展示用户的兴趣。
*   **编辑状态**: 使用组件的选择模式允许用户修改兴趣。
*   逻辑调整：
    *   加载数据时：`String` -> `Array`。
    *   保存数据时：`Array` -> `String`。

*   检查个人中心是否正确显示已选标签，且编辑功能正常。
